OVERVIEW
--------
TaxTrack is a native iOS + Android tax residency tracking app. It automatically
monitors your physical location across tax jurisdictions, counts days spent in
each, tracks the 183-day rule and similar thresholds, scores your audit risk,
and stores supporting documents as an evidence vault.

The original React Native / Expo project (TaxResidencyTracker/) was fully
replaced with native iOS (SwiftUI) and Android (Kotlin/Jetpack Compose) apps.
The RN folder has been permanently deleted.

KEY FEATURES
================================================================================

LOCATION TRACKING
  iOS:     CLLocationManager, allowsBackgroundLocationUpdates=true,
           5-minute interval, CLGeocoder reverse geocoding
  Android: FusedLocationProviderClient, 300s interval, Geocoder,
           ForegroundService with persistent notification

DATA MODEL
  LocationEntry  -- date (yyyy-MM-dd), jurisdictionId, city/state/country,
                    lat/lon, activityType, isVerified, source, notes
  Jurisdiction   -- name, type, color (hex), dayLimit, taxRule, isTracked,
                    isPrimary
  Document       -- type, title, date, imageData (JPEG), notes, extractedData
  UserProfile    -- name, primaryJurisdictionId, trackedJurisdictionIds,
                    hasCompletedOnboarding

TAX ENGINE
  - Counts unique days per jurisdiction per year
  - 183-day rule default (configurable per jurisdiction)
  - Audit risk score: starts at 100, deductions for threshold violations,
    bonus for high verification rate
  - Planning insights: compliance alerts, domicile opportunities, PR Act 60,
    FEIE exclusion

PERSISTENCE
  iOS:     UserDefaults + JSON (Codable)
  Android: SharedPreferences + Gson

IMPORT / EXPORT
  - CSV import: Monaeo-compatible format
  - JSON backup export (share sheet / Files)
  - JSON backup import (file picker)

DEFAULT JURISDICTIONS (14)
  New York (183d), California (183d), New Jersey (183d), Illinois (183d),
  Massachusetts (183d), Pennsylvania (183d), Connecticut (183d),
  Florida (366d), Texas (366d), Nevada (366d), Washington (366d),
  Puerto Rico (183d), US Federal (183d), United Kingdom (183d)

BUG FIXES APPLIED
================================================================================

1. LocationEntry missing Hashable conformance
   File: ios/TaxTrack/Models/Models.swift
   Fix:  Added Hashable to LocationEntry protocol list; required by iOS 17
         Map(position:selection:) API

2. Broken DateFormatter in updateDefaultTitle()
   File: ios/TaxTrack/Views/Documents/AddDocumentView.swift
   Fix:  Was using DateFormatter() with no dateFormat set (could not parse
         "yyyy-MM-dd" strings). Added explicit dateFormat = "yyyy-MM-dd" on
         input formatter and "MMM d, yyyy" on output formatter.

3. Unused showingEntryDetail state in MapView
   File: ios/TaxTrack/Views/Map/MapView.swift
   Fix:  Removed dead state variable; sheet was already controlled by
         sheet(item: $selectedEntry)

4. Missing Assets.xcassets
   File: ios/TaxTrack/Resources/Assets.xcassets/
   Fix:  Created AppIcon.appiconset (universal 1024x1024 placeholder) and
         AccentColor.colorset (#0A84FF); required for Xcode to build without
         ASSETCATALOG_COMPILER errors

HOW TO BUILD & RUN
================================================================================

iOS (requires macOS + Xcode 15+):
  1. git clone https://github.com/theoadoree/claude
  2. cd claude
  3. git checkout claude/tax-location-tracking-app-m6wwQ
  4. cd ios
  5. brew install xcodegen
  6. xcodegen generate
  7. open TaxTrack.xcodeproj
  8. Select your device/simulator, press Run (Cmd+R)
  NOTE: Background location requires a physical device (not simulator)

Android (requires Android Studio Hedgehog+):
  1. Clone repo as above
  2. Open android/ folder in Android Studio
  3. Let Gradle sync complete
  4. Run on emulator or device
  NOTE: Background location on Android 10+ requires granting "Allow all the
        time" in system settings after the in-app prompt
